### MinIO 설치

```bash
# 1. MinIO 네임스페이스 생성
kubectl create namespace minio

# 2. MinIO Helm 설치
helm repo add minio https://charts.min.io/
helm repo update

helm install minio minio/minio \
  --namespace minio \
  --set rootUser=minioadmin \
  --set rootPassword=minioadmin \
  --set mode=standalone \
  --set persistence.size=10Gi \
  --set resources.requests.memory=512Mi

# 3. MinIO Pod 확인
kubectl get pods -n minio

# 4. MinIO Console 접속 (선택)
kubectl port-forward -n minio svc/minio-console 9001:9001 &
# http://localhost:9001 (minioadmin / minioadmin)
```

### MinIO에서 버킷 생성

```bash
# MinIO Client 설치 (로컬)
# macOS
brew install minio/stable/mc

# Linux
wget https://dl.min.io/client/mc/release/linux-amd64/mc
chmod +x mc && sudo mv mc /usr/local/bin/

# MinIO 포트 포워딩
kubectl port-forward -n minio svc/minio 9000:9000 &

# MinIO alias 설정
mc alias set myminio http://localhost:9000 minioadmin minioadmin

# Thanos용 버킷 생성
mc mb myminio/thanos

# 버킷 확인
mc ls myminio
```

## 🛠️ Part 2: Thanos 구성 (2시간)

### 실습 1: Object Store 설정 Secret 생성 (15분)

**목표**: Thanos가 Object Storage에 접근하기 위한 설정

```bash
# Object Store 설정 파일 생성
cat << 'EOF' > objstore.yml
type: S3
config:
  bucket: thanos
  endpoint: minio.minio.svc:9000
  access_key: minioadmin
  secret_key: minioadmin
  insecure: true
  signature_version2: false
EOF

# Secret 생성
kubectl create secret generic thanos-objstore-config \
  --from-file=objstore.yml=objstore.yml \
  --namespace monitoring

# 확인
kubectl get secret -n monitoring thanos-objstore-config
```

**AWS S3용 설정** (참고):
```yaml
type: S3
config:
  bucket: my-thanos-bucket
  endpoint: s3.ap-northeast-2.amazonaws.com
  region: ap-northeast-2
  # AWS IAM Role 사용 시 access_key, secret_key 생략
  # access_key: xxx
  # secret_key: xxx
```

### 실습 2: Prometheus에 Thanos Sidecar 활성화 (30분)

**목표**: Prometheus Pod에 Sidecar 컨테이너 추가

```bash
# values-thanos.yaml 생성
cat << 'EOF' > values-thanos.yaml
prometheus:
  prometheusSpec:
    # external_labels 설정 (필수!)
    externalLabels:
      cluster: my-cluster
      env: production
    
    # Thanos Sidecar 활성화
    thanos:
      create: true
      image: quay.io/thanos/thanos:v0.34.1
      version: v0.34.1
      objectStorageConfig:
        key: objstore.yml
        name: thanos-objstore-config
      
      # Sidecar 리소스
      resources:
        requests:
          cpu: 100m
          memory: 256Mi
        limits:
          cpu: 500m
          memory: 512Mi
    
    # 보관 기간 (Sidecar가 업로드하면 줄일 수 있음)
    retention: 6h
    retentionSize: ""
    
    # 디스크 설정
    storageSpec:
      volumeClaimTemplate:
        spec:
          accessModes: ["ReadWriteOnce"]
          resources:
            requests:
              storage: 20Gi
EOF

# Helm 업그레이드
helm upgrade prometheus prometheus-community/kube-prometheus-stack \
  --namespace monitoring \
  --values values-thanos.yaml \
  --reuse-values

# Pod 재시작 확인 (Sidecar 포함)
kubectl get pods -n monitoring -l app.kubernetes.io/name=prometheus -w
```

**Sidecar 확인**:
```bash
# Pod 상세 확인 (2개 컨테이너: prometheus, thanos-sidecar)
kubectl describe pod -n monitoring prometheus-prometheus-kube-prometheus-prometheus-0 | grep -A5 "Containers:"

# Sidecar 로그 확인
kubectl logs -n monitoring prometheus-prometheus-kube-prometheus-prometheus-0 -c thanos-sidecar
```

**예상 로그**:
```
level=info msg="starting Thanos Sidecar"
level=info msg="Listening for StoreAPI on" address=0.0.0.0:10901
level=info msg="successfully uploaded block" block=01ABCD...
```

### 실습 3: Thanos Query 배포 (30분)

**목표**: 통합 쿼리 엔드포인트 설치

```bash
# Thanos Query Deployment
cat << 'EOF' | kubectl apply -f -
apiVersion: apps/v1
kind: Deployment
metadata:
  name: thanos-query
  namespace: monitoring
  labels:
    app: thanos-query
spec:
  replicas: 2
  selector:
    matchLabels:
      app: thanos-query
  template:
    metadata:
      labels:
        app: thanos-query
    spec:
      containers:
      - name: thanos-query
        image: quay.io/thanos/thanos:v0.34.1
        args:
        - query
        - --log.level=info
        - --query.replica-label=prometheus_replica
        - --query.replica-label=replica
        # Sidecar 연결 (DNS 서비스 디스커버리)
        - --store=dnssrv+_grpc._tcp.prometheus-operated.monitoring.svc.cluster.local
        # Store Gateway 연결 (나중에 추가)
        # - --store=thanos-store-gateway:10901
        ports:
        - name: http
          containerPort: 10902
        - name: grpc
          containerPort: 10901
        resources:
          requests:
            cpu: 100m
            memory: 256Mi
          limits:
            cpu: 1
            memory: 1Gi
        livenessProbe:
          httpGet:
            path: /-/healthy
            port: http
        readinessProbe:
          httpGet:
            path: /-/ready
            port: http
---
apiVersion: v1
kind: Service
metadata:
  name: thanos-query
  namespace: monitoring
spec:
  selector:
    app: thanos-query
  ports:
  - name: http
    port: 10902
    targetPort: http
  - name: grpc
    port: 10901
    targetPort: grpc
EOF

# 확인
kubectl get pods -n monitoring -l app=thanos-query
kubectl get svc -n monitoring thanos-query
```

**Thanos Query UI 접속**:
```bash
kubectl port-forward -n monitoring svc/thanos-query 10902:10902 &
# http://localhost:10902
```

### 실습 4: Thanos Store Gateway 배포 (30분)

**목표**: Object Storage의 과거 데이터 조회용 컴포넌트

```bash
cat << 'EOF' | kubectl apply -f -
apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: thanos-store-gateway
  namespace: monitoring
spec:
  replicas: 1
  serviceName: thanos-store-gateway
  selector:
    matchLabels:
      app: thanos-store-gateway
  template:
    metadata:
      labels:
        app: thanos-store-gateway
    spec:
      containers:
      - name: thanos-store
        image: quay.io/thanos/thanos:v0.34.1
        args:
        - store
        - --log.level=info
        - --data-dir=/var/thanos/store
        - --objstore.config-file=/etc/thanos/objstore.yml
        - --index-cache-size=500MB
        ports:
        - name: grpc
          containerPort: 10901
        - name: http
          containerPort: 10902
        volumeMounts:
        - name: objstore-config
          mountPath: /etc/thanos
        - name: data
          mountPath: /var/thanos/store
        resources:
          requests:
            cpu: 100m
            memory: 512Mi
          limits:
            cpu: 1
            memory: 2Gi
      volumes:
      - name: objstore-config
        secret:
          secretName: thanos-objstore-config
  volumeClaimTemplates:
  - metadata:
      name: data
    spec:
      accessModes: ["ReadWriteOnce"]
      resources:
        requests:
          storage: 10Gi
---
apiVersion: v1
kind: Service
metadata:
  name: thanos-store-gateway
  namespace: monitoring
spec:
  selector:
    app: thanos-store-gateway
  ports:
  - name: grpc
    port: 10901
  - name: http
    port: 10902
EOF

# Query에 Store Gateway 연결 추가
kubectl patch deployment thanos-query -n monitoring --type='json' -p='[
  {"op": "add", "path": "/spec/template/spec/containers/0/args/-", "value": "--store=thanos-store-gateway:10901"}
]'

# 확인
kubectl get pods -n monitoring -l app=thanos-store-gateway
```

### 실습 5: Thanos Compactor 배포 (15분)

**목표**: 블록 압축 및 다운샘플링

```bash
cat << 'EOF' | kubectl apply -f -
apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: thanos-compactor
  namespace: monitoring
spec:
  replicas: 1
  serviceName: thanos-compactor
  selector:
    matchLabels:
      app: thanos-compactor
  template:
    metadata:
      labels:
        app: thanos-compactor
    spec:
      containers:
      - name: thanos-compactor
        image: quay.io/thanos/thanos:v0.34.1
        args:
        - compact
        - --log.level=info
        - --data-dir=/var/thanos/compact
        - --objstore.config-file=/etc/thanos/objstore.yml
        - --retention.resolution-raw=30d
        - --retention.resolution-5m=90d
        - --retention.resolution-1h=365d
        - --wait
        volumeMounts:
        - name: objstore-config
          mountPath: /etc/thanos
        - name: data
          mountPath: /var/thanos/compact
        resources:
          requests:
            cpu: 100m
            memory: 512Mi
      volumes:
      - name: objstore-config
        secret:
          secretName: thanos-objstore-config
  volumeClaimTemplates:
  - metadata:
      name: data
    spec:
      accessModes: ["ReadWriteOnce"]
      resources:
        requests:
          storage: 20Gi
EOF
```
