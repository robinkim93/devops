## 📚 핵심 개념 복습

### 1. Grafana 핵심

```
┌─────────────────────────────────────────────────────────────┐
│  Grafana 기억할 것                                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  핵심 구성 요소:                                            │
│  - Data Source: 데이터 원본 (Prometheus, Thanos, Loki)     │
│  - Dashboard: 여러 패널의 모음                              │
│  - Panel: 단일 시각화 (Time series, Stat, Gauge...)       │
│  - Variable: 동적 필터 ($namespace, $pod)                  │
│                                                             │
│  패널 타입 선택:                                            │
│  - 시간 변화 → Time series                                 │
│  - 현재 값 → Stat                                          │
│  - 백분율 → Gauge                                          │
│  - 목록 → Table                                            │
│                                                             │
│  Variables:                                                 │
│  - Query: label_values(metric, label)                      │
│  - Multi-value: 여러 값 선택                               │
│  - Include All: "All" 옵션 추가                            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2. Thanos 아키텍처

```
┌─────────────────────────────────────────────────────────────────────────┐
│                      Thanos 컴포넌트 요약                               │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  ┌─────────────┐     ┌─────────────┐     ┌─────────────┐              │
│  │   Sidecar   │     │    Query    │     │ Store GW    │              │
│  │ Prometheus  │────→│  통합 쿼리   │←────│ Object      │              │
│  │ 에 붙어서   │     │  엔드포인트  │     │ Storage     │              │
│  │ 블록 업로드 │     │  (Grafana)  │     │ 조회        │              │
│  └──────┬──────┘     └─────────────┘     └──────┬──────┘              │
│         │                                        │                     │
│         │         ┌─────────────┐               │                     │
│         └────────→│  Object     │←──────────────┘                     │
│                   │  Storage    │                                      │
│                   │  (S3, GCS)  │←──────────────┐                     │
│                   └──────┬──────┘               │                     │
│                          │                      │                     │
│                          ▼              ┌───────┴───────┐             │
│                   ┌─────────────┐       │   Compactor   │             │
│                   │  장기 저장  │       │ 압축/다운샘플 │             │
│                   │  (무제한)   │       └───────────────┘             │
│                   └─────────────┘                                      │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 3. 핵심 설정

```yaml
# Prometheus external_labels (필수!)
global:
  external_labels:
    cluster: my-cluster
    env: production
    replica: prometheus-a  # HA 시 deduplication용

# Object Store 설정
type: S3
config:
  bucket: thanos
  endpoint: s3.amazonaws.com
  region: ap-northeast-2

# Compactor 보관 정책
retention:
  resolution_raw: 30d    # 원본: 30일
  resolution_5m: 90d     # 5분 해상도: 90일
  resolution_1h: 365d    # 1시간 해상도: 1년
```

### 4. Grafana Alerting vs Prometheus Alerting

| 항목 | Grafana Alerting | Prometheus Alerting |
|------|------------------|---------------------|
| 데이터 소스 | 모든 소스 | Prometheus만 |
| 설정 방식 | UI (쉬움) | YAML (GitOps) |
| 알림 이력 | 내장 | 별도 필요 |
| 사용 케이스 | 빠른 설정, 로그 알림 | 메트릭 알림 표준 |

### 실습 2: 통합 대시보드 생성 (40분)

**목표**: Week 17-18 내용을 활용한 종합 대시보드

```
대시보드 이름: My Service Overview
Data Source: Thanos

Variables:
- namespace: label_values(kube_pod_info, namespace)
- pod: label_values(kube_pod_info{namespace=~"$namespace"}, pod)
```

**Row 1: 서비스 현황 (Stat 패널들)**

```promql
# 패널 1: Running Pods
count(kube_pod_status_phase{namespace=~"$namespace", phase="Running"})

# 패널 2: CPU 사용률 평균
avg(
  sum(rate(container_cpu_usage_seconds_total{namespace=~"$namespace", container!=""}[5m])) by (pod)
  /
  sum(kube_pod_container_resource_limits{namespace=~"$namespace", resource="cpu"}) by (pod)
) * 100

# 패널 3: 메모리 사용률 평균
avg(
  sum(container_memory_usage_bytes{namespace=~"$namespace", container!=""}) by (pod)
  /
  sum(kube_pod_container_resource_limits{namespace=~"$namespace", resource="memory"}) by (pod)
) * 100
```

**Row 2: 리소스 사용량 (Time series)**

```promql
# 패널 4: Pod별 CPU
sum(rate(container_cpu_usage_seconds_total{namespace=~"$namespace", pod=~"$pod", container!=""}[5m])) by (pod)

# 패널 5: Pod별 메모리
sum(container_memory_usage_bytes{namespace=~"$namespace", pod=~"$pod", container!=""}) by (pod)
```

**Row 3: 상세 정보 (Table)**

```promql
# 패널 6: Pod 상태 테이블
kube_pod_status_phase{namespace=~"$namespace"} == 1
# Transform: Labels to fields
# Columns: pod, phase, namespace
```

### 실습 3: 장기 데이터 분석 쿼리 (20분)

```promql
# 1. 지난 7일간 CPU 트렌드
avg_over_time(
  (100 - (avg by(instance) (irate(node_cpu_seconds_total{mode="idle"}[5m])) * 100))
  [7d:1h]
)

# 2. 지난 30일간 에러율 변화 (Recording Rule 있다면)
# max_over_time(job:http_error_rate:ratio[30d:1d])

# 3. 클러스터별 리소스 사용량 비교
sum(container_memory_usage_bytes{container!=""}) by (cluster) / 1024/1024/1024
```
