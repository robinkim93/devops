# 📅 Day 128: Grafana 대시보드 기초

## 🎯 오늘의 목표

## 📚 Part 1: 핵심 개념 (40분)

### Grafana란?

```
┌─────────────────────────────────────────────────────────────┐
│  Grafana = 메트릭 시각화 + 대시보드 + 알림                   │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  핵심 기능:                                                  │
│  1. 다양한 데이터 소스 연결 (Prometheus, Loki, ES...)       │
│  2. 풍부한 시각화 옵션 (그래프, 게이지, 테이블...)          │
│  3. 대시보드 템플릿과 변수                                   │
│  4. 알림 기능 (Grafana Alerting)                            │
│  5. 사용자/팀 관리                                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 왜 Grafana인가?

```
┌─────────────────────────────────────────────────────────────┐
│  Prometheus UI vs Grafana                                    │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Prometheus UI:                                              │
│  - 간단한 쿼리 테스트용                                      │
│  - 단일 그래프만 표시                                        │
│  - 저장/공유 불가                                            │
│                                                             │
│  Grafana:                                                    │
│  - 여러 패널을 하나의 대시보드에                             │
│  - 변수로 동적 필터링                                        │
│  - 대시보드 저장, 공유, 내보내기                             │
│  - 팀별 권한 관리                                            │
│  - 다양한 데이터 소스 통합                                   │
│                                                             │
│  → 운영 대시보드는 반드시 Grafana로!                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### Grafana 아키텍처

```
┌─────────────────────────────────────────────────────────────────────────┐
│                         Grafana Architecture                            │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│                        ┌───────────────────────┐                        │
│                        │     Grafana Server    │                        │
│                        │                       │                        │
│                        │  ┌─────────────────┐ │                        │
│                        │  │    Frontend     │ │    ← React SPA         │
│                        │  └────────┬────────┘ │                        │
│                        │           │          │                        │
│                        │  ┌────────┴────────┐ │                        │
│                        │  │     Backend     │ │    ← Go                │
│                        │  └────────┬────────┘ │                        │
│                        │           │          │                        │
│                        │  ┌────────┴────────┐ │                        │
│                        │  │    Database     │ │    ← SQLite/PostgreSQL │
│                        │  └─────────────────┘ │    (설정, 대시보드 저장)│
│                        └───────────┬───────────┘                        │
│                                    │                                    │
│              ┌─────────────────────┼─────────────────────┐             │
│              │                     │                     │             │
│              ▼                     ▼                     ▼             │
│        ┌───────────┐        ┌───────────┐        ┌───────────┐        │
│        │Prometheus │        │   Loki    │        │Elasticsearch│       │
│        │(Metrics)  │        │  (Logs)   │        │ (Logs)     │        │
│        └───────────┘        └───────────┘        └───────────┘        │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘
```

### 핵심 구성 요소

| 구성 요소 | 설명 |
|----------|------|
| **Data Source** | 데이터를 가져올 원본 (Prometheus, Loki 등) |
| **Dashboard** | 여러 패널을 모은 화면 |
| **Panel** | 단일 시각화 요소 (그래프, 게이지 등) |
| **Row** | 패널들을 묶는 접을 수 있는 그룹 |
| **Variable** | 대시보드에서 사용할 동적 값 |
| **Annotation** | 그래프에 이벤트 표시 (배포, 장애 등) |

### 패널 타입

| 타입 | 용도 | 사용 예시 |
|------|------|----------|
| **Time series** | 시간에 따른 변화 | CPU 사용률, 요청 수 |
| **Stat** | 단일 숫자 강조 | 현재 에러율, 활성 사용자 수 |
| **Gauge** | 범위 내 현재 값 | 디스크 사용률 (0-100%) |
| **Bar gauge** | 여러 값 비교 | 서비스별 응답시간 |
| **Table** | 상세 데이터 목록 | Pod 목록, 알림 현황 |
| **Heatmap** | 분포 시각화 | 응답시간 히스토그램 |
| **Pie chart** | 비율 표시 | 상태 코드별 비율 |
| **Logs** | 로그 표시 | Loki 로그 (Prometheus X) |

### 실습 3: 기본 대시보드 분석 (25분)

**목표**: 잘 만들어진 대시보드 구조 학습

```
Dashboards → Browse → Kubernetes / Compute Resources / Namespace (Pods)
```

**분석할 요소**:

1. **변수 (Variables)**:
   ```
   상단에 드롭다운 확인:
   - datasource: 데이터 소스 선택
   - cluster: 클러스터 선택
   - namespace: 네임스페이스 선택
   
   → 변수를 바꾸면 모든 패널이 자동 업데이트
   ```

2. **Row 구조**:
   ```
   - CPU Quota: CPU 관련 패널 그룹
   - Memory Quota: 메모리 관련 패널 그룹
   - 접기/펼치기 가능
   ```

3. **패널 쿼리 확인**:
   ```
   1. 패널 제목 클릭 → Edit
   2. Query 탭에서 PromQL 확인
   3. Transform, Override 탭 확인
   ```

**예시 쿼리 분석**:
```promql
# CPU Usage 패널의 쿼리
sum(rate(container_cpu_usage_seconds_total{namespace="$namespace", pod=~"$pod", container!=""}[5m])) by (pod)

# 분석:
# - $namespace, $pod: 변수 참조
# - container!="": POD 컨테이너 제외
# - by (pod): Pod별로 집계
```

### 실습 4: 첫 번째 대시보드 생성 (30분)

**목표**: 직접 대시보드와 패널 생성

```
1. 좌측 메뉴 → + → Dashboard
2. "Add visualization" 클릭
```

**패널 1: 노드 CPU 사용률 (Time series)**

```
Query:
100 - (avg by(instance) (irate(node_cpu_seconds_total{mode="idle"}[5m])) * 100)

설정:
- Title: Node CPU Usage (%)
- Legend: {{ instance }}
- Unit: Percent (0-100)
- Thresholds: 70 (yellow), 90 (red)
```

**패널 2: 메모리 사용률 (Gauge)**

```
Query:
(1 - (node_memory_MemAvailable_bytes / node_memory_MemTotal_bytes)) * 100

설정:
- Title: Memory Usage
- Type: Gauge
- Unit: Percent (0-100)
- Min: 0, Max: 100
- Thresholds: 70 (yellow), 85 (red)
```

**패널 3: 활성 Pod 수 (Stat)**

```
Query:
count(kube_pod_status_phase{phase="Running"})

설정:
- Title: Running Pods
- Type: Stat
- Color mode: Value
- Graph mode: None
```

**패널 4: 네임스페이스별 CPU 사용량 (Bar gauge)**

```
Query:
sum(rate(container_cpu_usage_seconds_total{container!=""}[5m])) by (namespace)

설정:
- Title: CPU by Namespace
- Type: Bar gauge
- Orientation: Horizontal
- Display mode: Gradient
```

**대시보드 저장**:
```
1. 상단 💾 아이콘 클릭
2. Title: My First Dashboard
3. Folder: General
4. Save
```

### 실습 5: 패널 세부 설정 (20분)

**목표**: 패널 옵션 심화 학습

**Panel Options**:
```
- Title: 패널 제목
- Description: 마우스 오버 시 설명
- Transparent: 배경 투명
- Repeat: 변수별로 패널 반복
```

**Standard Options**:
```
- Unit: 단위 설정 (bytes, percent, seconds...)
- Min/Max: 값 범위 제한
- Decimals: 소수점 자릿수
- Display name: 범례 이름 오버라이드
- Color scheme: 색상 스키마
```

**Thresholds**:
```
- 값에 따른 색상 변경
- 예: 
  - Base (녹색): 0-70
  - Yellow: 70-90
  - Red: 90+
```

**Value mappings**:
```
- 특정 값을 텍스트로 변환
- 예: 1 → "Running", 0 → "Down"
```
