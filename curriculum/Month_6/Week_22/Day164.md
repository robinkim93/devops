## 📚 핵심 개념 정리

### 1. Terraform 워크플로우

```
Write → Init → Plan → Apply → (Destroy)

terraform init     # Provider 다운로드, Backend 초기화
terraform validate # 문법 검증
terraform plan     # 변경 미리보기
terraform apply    # 실제 적용
terraform destroy  # 리소스 삭제
```

### 2. 변수 우선순위

```
높음 ────────────────────────────────────────────── 낮음

1. -var, -var-file  →  2. *.auto.tfvars  →  3. terraform.tfvars
→  4. TF_VAR_*  →  5. default 값
```

### 3. State 관리

```hcl
# Remote Backend 설정
terraform {
  backend "s3" {
    bucket         = "my-terraform-state"
    key            = "prod/terraform.tfstate"
    region         = "ap-northeast-2"
    encrypt        = true
    dynamodb_table = "terraform-locks"
  }
}
```

### 4. 모듈 구조

```
project/
├── main.tf
├── variables.tf
├── outputs.tf
└── modules/
    ├── vpc/
    │   ├── main.tf
    │   ├── variables.tf
    │   └── outputs.tf
    ├── eks/
    └── rds/
```

## 🔑 핵심 명령어 모음

### 기본 명령어

```bash
# 초기화 및 검증
terraform init              # 초기화
terraform init -upgrade     # Provider 업그레이드
terraform validate          # 문법 검증
terraform fmt -recursive    # 코드 포맷팅

# 계획 및 적용
terraform plan              # 변경 미리보기
terraform plan -out=plan.out # 계획 저장
terraform apply             # 적용
terraform apply plan.out    # 저장된 계획 적용
terraform apply -auto-approve # 자동 승인

# 삭제
terraform destroy           # 전체 삭제
terraform destroy -target=aws_instance.example # 특정 리소스
```

### State 명령어

```bash
# State 조회
terraform state list        # 리소스 목록
terraform state show <resource> # 상세 정보
terraform state pull        # Remote → Local

# State 조작
terraform state mv <src> <dst>  # 이동/이름변경
terraform state rm <resource>   # State에서 제거
terraform force-unlock <ID>     # Lock 해제
```

### Output 명령어

```bash
terraform output            # 모든 출력
terraform output -raw name  # Raw 값
terraform output -json      # JSON 형식
```

## 🔍 자주 발생하는 문제와 해결

### 1. State Lock 오류

```
Error: Error acquiring the state lock
```

```bash
# 해결
terraform force-unlock <LOCK_ID>
```

### 2. Provider 초기화 실패

```
Error: Failed to query available provider packages
```

```bash
# 해결
terraform init -upgrade
```

### 3. 리소스 충돌

```
Error: resource already exists
```

```bash
# 해결: 기존 리소스 import
terraform import aws_instance.example i-1234567890abcdef0
```

### 4. Cycle 오류

```
Error: Cycle: module.a, module.b
```

```bash
# 해결: 의존성 분리
# depends_on 명시적 설정
```
