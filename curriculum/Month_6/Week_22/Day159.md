## 📚 Part 1: 변수 (Variables)

### 변수 선언 방법

```hcl
# variables.tf

# 기본 문자열 변수
variable "environment" {
  description = "Environment name (dev, staging, prod)"
  type        = string
  default     = "dev"
}

# 필수 변수 (default 없음)
variable "project_name" {
  description = "Project name for resource naming"
  type        = string
  # default 없으면 필수 입력
}

# 민감 정보
variable "db_password" {
  description = "Database password"
  type        = string
  sensitive   = true  # 로그에 표시 안됨
}
```

### 변수 타입

```hcl
# 1. Primitive Types

variable "instance_count" {
  type    = number
  default = 2
}

variable "enable_monitoring" {
  type    = bool
  default = true
}

variable "region" {
  type    = string
  default = "ap-northeast-2"
}

# 2. Collection Types

# List: 순서가 있는 동일 타입 모음
variable "availability_zones" {
  type    = list(string)
  default = ["ap-northeast-2a", "ap-northeast-2b", "ap-northeast-2c"]
}

# Map: 키-값 쌍
variable "instance_types" {
  type = map(string)
  default = {
    dev  = "t3.micro"
    prod = "t3.medium"
  }
}

# Set: 중복 없는 모음
variable "allowed_ports" {
  type    = set(number)
  default = [22, 80, 443]
}

# 3. Structural Types

# Object: 다양한 타입의 속성
variable "vpc_config" {
  type = object({
    cidr_block         = string
    enable_dns_support = bool
    tags               = map(string)
  })
  default = {
    cidr_block         = "10.0.0.0/16"
    enable_dns_support = true
    tags               = { Name = "main-vpc" }
  }
}

# Tuple: 순서가 있는 다양한 타입
variable "instance_spec" {
  type    = tuple([string, number, bool])
  default = ["t3.micro", 2, true]
}
```

### 변수 값 설정 방법 (우선순위)

```
우선순위 (높은 순):
1. -var 또는 -var-file 옵션
2. *.auto.tfvars 파일 (자동 로드)
3. terraform.tfvars 파일 (자동 로드)
4. 환경변수 TF_VAR_name
5. 변수 선언의 default 값
```

```bash
# 방법 1: 명령줄
terraform apply -var="environment=prod" -var="instance_count=3"

# 방법 2: -var-file
terraform apply -var-file="production.tfvars"

# 방법 3: 환경변수
export TF_VAR_environment="prod"
export TF_VAR_db_password="secret123"

# 방법 4: terraform.tfvars (자동 로드)
# terraform.tfvars
environment    = "prod"
instance_count = 3

# 방법 5: *.auto.tfvars (자동 로드)
# prod.auto.tfvars
environment = "prod"
```

### 변수 검증 (Validation)

```hcl
variable "environment" {
  type        = string
  description = "Environment name"
  
  validation {
    condition     = contains(["dev", "staging", "prod"], var.environment)
    error_message = "Environment must be dev, staging, or prod."
  }
}

variable "instance_type" {
  type = string
  
  validation {
    condition     = can(regex("^t3\\.", var.instance_type))
    error_message = "Instance type must start with t3."
  }
}

variable "cidr_block" {
  type = string
  
  validation {
    condition     = can(cidrhost(var.cidr_block, 0))
    error_message = "Must be a valid CIDR block."
  }
}
```

### 변수 사용

```hcl
# var.변수명 으로 사용
resource "aws_instance" "example" {
  ami           = data.aws_ami.amazon_linux.id
  instance_type = var.instance_types[var.environment]  # map 접근
  count         = var.instance_count
  
  tags = {
    Name        = "${var.project_name}-${var.environment}-${count.index + 1}"
    Environment = var.environment
  }
}

# List 접근
resource "aws_subnet" "public" {
  count             = length(var.availability_zones)
  availability_zone = var.availability_zones[count.index]
  cidr_block        = cidrsubnet(var.vpc_config.cidr_block, 8, count.index)
}
```

## 📚 Part 2: Local Values

### Local 값 선언

```hcl
# locals.tf
locals {
  # 단순 값
  project_name = "tossplace-clone"
  environment  = var.environment
  
  # 계산된 값
  name_prefix = "${local.project_name}-${local.environment}"
  
  # 조건부 값
  instance_type = var.environment == "prod" ? "t3.medium" : "t3.micro"
  
  # 공통 태그
  common_tags = {
    Project     = local.project_name
    Environment = local.environment
    ManagedBy   = "terraform"
    CreatedAt   = timestamp()
  }
  
  # 복잡한 계산
  subnet_cidrs = {
    for i, az in var.availability_zones :
    az => cidrsubnet(var.vpc_cidr, 8, i)
  }
}
```

### Local 사용

```hcl
resource "aws_vpc" "main" {
  cidr_block = var.vpc_cidr
  
  tags = merge(local.common_tags, {
    Name = "${local.name_prefix}-vpc"
  })
}

resource "aws_instance" "example" {
  instance_type = local.instance_type
  
  tags = local.common_tags
}
```

### Variable vs Local

| Variable | Local |
|----------|-------|
| 외부에서 값 전달 | 내부에서 계산/정의 |
| 모듈 인터페이스 | 코드 중복 제거 |
| `var.name` | `local.name` |
| tfvars로 오버라이드 | 오버라이드 불가 |

## 📚 Part 3: 모듈 (Modules)

### 모듈이란?

```
모듈 = 재사용 가능한 Terraform 코드 패키지

장점:
├── 코드 재사용
├── 추상화 (복잡성 숨김)
├── 일관성 유지
├── 테스트 용이
└── 팀 간 공유
```

### 모듈 디렉토리 구조

```
project/
├── main.tf              # 루트 모듈
├── variables.tf
├── outputs.tf
├── terraform.tfvars
│
└── modules/             # 로컬 모듈
    ├── vpc/
    │   ├── main.tf
    │   ├── variables.tf
    │   └── outputs.tf
    │
    ├── eks/
    │   ├── main.tf
    │   ├── variables.tf
    │   └── outputs.tf
    │
    └── rds/
        ├── main.tf
        ├── variables.tf
        └── outputs.tf
```

### 모듈 작성 예시: VPC 모듈

```hcl
# modules/vpc/variables.tf
variable "name" {
  description = "Name prefix for resources"
  type        = string
}

variable "cidr_block" {
  description = "VPC CIDR block"
  type        = string
  default     = "10.0.0.0/16"
}

variable "availability_zones" {
  description = "List of availability zones"
  type        = list(string)
}

variable "enable_nat_gateway" {
  description = "Enable NAT Gateway"
  type        = bool
  default     = true
}

variable "tags" {
  description = "Additional tags"
  type        = map(string)
  default     = {}
}
```

```hcl
# modules/vpc/main.tf
resource "aws_vpc" "main" {
  cidr_block           = var.cidr_block
  enable_dns_hostnames = true
  enable_dns_support   = true

  tags = merge(var.tags, {
    Name = "${var.name}-vpc"
  })
}

resource "aws_subnet" "public" {
  count = length(var.availability_zones)

  vpc_id                  = aws_vpc.main.id
  cidr_block              = cidrsubnet(var.cidr_block, 8, count.index)
  availability_zone       = var.availability_zones[count.index]
  map_public_ip_on_launch = true

  tags = merge(var.tags, {
    Name = "${var.name}-public-${var.availability_zones[count.index]}"
    Type = "public"
  })
}

resource "aws_subnet" "private" {
  count = length(var.availability_zones)

  vpc_id            = aws_vpc.main.id
  cidr_block        = cidrsubnet(var.cidr_block, 8, count.index + 10)
  availability_zone = var.availability_zones[count.index]

  tags = merge(var.tags, {
    Name = "${var.name}-private-${var.availability_zones[count.index]}"
    Type = "private"
  })
}

resource "aws_internet_gateway" "main" {
  vpc_id = aws_vpc.main.id

  tags = merge(var.tags, {
    Name = "${var.name}-igw"
  })
}

resource "aws_eip" "nat" {
  count  = var.enable_nat_gateway ? 1 : 0
  domain = "vpc"

  tags = merge(var.tags, {
    Name = "${var.name}-nat-eip"
  })
}

resource "aws_nat_gateway" "main" {
  count = var.enable_nat_gateway ? 1 : 0

  allocation_id = aws_eip.nat[0].id
  subnet_id     = aws_subnet.public[0].id

  tags = merge(var.tags, {
    Name = "${var.name}-nat"
  })
}
```

```hcl
# modules/vpc/outputs.tf
output "vpc_id" {
  description = "VPC ID"
  value       = aws_vpc.main.id
}

output "vpc_cidr" {
  description = "VPC CIDR block"
  value       = aws_vpc.main.cidr_block
}

output "public_subnet_ids" {
  description = "List of public subnet IDs"
  value       = aws_subnet.public[*].id
}

output "private_subnet_ids" {
  description = "List of private subnet IDs"
  value       = aws_subnet.private[*].id
}

output "nat_gateway_id" {
  description = "NAT Gateway ID"
  value       = var.enable_nat_gateway ? aws_nat_gateway.main[0].id : null
}
```

### 모듈 호출

```hcl
# 루트 모듈 main.tf

# 로컬 모듈 호출
module "vpc" {
  source = "./modules/vpc"

  name               = local.name_prefix
  cidr_block         = "10.0.0.0/16"
  availability_zones = ["ap-northeast-2a", "ap-northeast-2b", "ap-northeast-2c"]
  enable_nat_gateway = var.environment == "prod"
  
  tags = local.common_tags
}

# 모듈 출력 사용
resource "aws_instance" "example" {
  subnet_id = module.vpc.private_subnet_ids[0]
  
  tags = {
    VPC = module.vpc.vpc_id
  }
}

# 레지스트리 모듈 호출
module "eks" {
  source  = "terraform-aws-modules/eks/aws"
  version = "~> 19.0"

  cluster_name    = "${local.name_prefix}-eks"
  cluster_version = "1.28"

  vpc_id     = module.vpc.vpc_id
  subnet_ids = module.vpc.private_subnet_ids
}
```

### 모듈 소스 종류

```hcl
# 로컬 경로
module "vpc" {
  source = "./modules/vpc"
}

# 공식 레지스트리
module "eks" {
  source  = "terraform-aws-modules/eks/aws"
  version = "~> 19.0"
}

# GitHub
module "vpc" {
  source = "github.com/terraform-aws-modules/terraform-aws-vpc?ref=v5.0.0"
}

# S3
module "vpc" {
  source = "s3::https://s3-ap-northeast-2.amazonaws.com/my-bucket/vpc.zip"
}

# Git
module "vpc" {
  source = "git::https://github.com/org/modules.git//vpc?ref=v1.0.0"
}
```

## 📚 Part 4: Output Values

### Output 정의

```hcl
# outputs.tf

# 기본 출력
output "vpc_id" {
  description = "The ID of the VPC"
  value       = aws_vpc.main.id
}

# 민감 정보
output "db_password" {
  description = "Database password"
  value       = random_password.db.result
  sensitive   = true
}

# 조건부 출력
output "load_balancer_dns" {
  description = "Load balancer DNS name"
  value       = var.create_alb ? aws_lb.main[0].dns_name : null
}

# 복잡한 구조
output "subnets" {
  description = "Subnet information"
  value = {
    public  = aws_subnet.public[*].id
    private = aws_subnet.private[*].id
  }
}
```

### Output 조회

```bash
# 모든 출력 표시
terraform output

# 특정 출력
terraform output vpc_id

# JSON 형식
terraform output -json

# Raw 값 (따옴표 없이)
terraform output -raw vpc_id

# 스크립트에서 사용
VPC_ID=$(terraform output -raw vpc_id)
echo $VPC_ID
```

## 🔑 핵심 명령어

```bash
# 변수 관련
terraform plan -var="key=value"       # 명령줄 변수
terraform apply -var-file="prod.tfvars"  # 파일로 변수
export TF_VAR_name=value              # 환경변수

# 출력 관련
terraform output                      # 모든 출력
terraform output -raw name            # 특정 출력 (raw)
terraform output -json                # JSON 형식

# 모듈 관련
terraform init -upgrade              # 모듈 업데이트
terraform get                        # 모듈 다운로드
```
