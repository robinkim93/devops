## 🛠️ Part 2: 실습 (2시간)

### 실습 1: AWS CLI 설치 및 설정 (30분)

**목표**: AWS CLI를 설치하고 자격증명을 설정

```bash
# macOS
brew install awscli

# Linux
curl "https://awscli.amazonaws.com/awscli-exe-linux-x86_64.zip" -o "awscliv2.zip"
unzip awscliv2.zip
sudo ./aws/install

# 버전 확인
aws --version

# 자격증명 설정
aws configure
# AWS Access Key ID [None]: AKIAIOSFODNN7EXAMPLE
# AWS Secret Access Key [None]: wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY
# Default region name [None]: ap-northeast-2
# Default output format [None]: json

# 설정 확인
aws sts get-caller-identity
```

**예상 출력**:
```json
{
    "UserId": "AIDAXXXXXXXXXX",
    "Account": "123456789012",
    "Arn": "arn:aws:iam::123456789012:user/myuser"
}
```

**분석 포인트**:
- `UserId`: IAM 사용자 고유 ID
- `Account`: AWS 계정 번호 (12자리)
- `Arn`: Amazon Resource Name (리소스 식별자)

### 실습 2: 기본 AWS CLI 명령어 (30분)

**목표**: 주요 서비스 상태 확인

```bash
# 1. EC2 인스턴스 목록
aws ec2 describe-instances \
  --query 'Reservations[].Instances[].[InstanceId,State.Name,InstanceType,Tags[?Key==`Name`].Value|[0]]' \
  --output table

# 2. S3 버킷 목록
aws s3 ls

# 3. S3 버킷 내용 확인
aws s3 ls s3://bucket-name/

# 4. VPC 목록
aws ec2 describe-vpcs \
  --query 'Vpcs[].[VpcId,CidrBlock,Tags[?Key==`Name`].Value|[0]]' \
  --output table

# 5. EKS 클러스터 목록
aws eks list-clusters

# 6. EKS 클러스터 상세 정보
aws eks describe-cluster --name my-cluster

# 7. RDS 인스턴스 목록
aws rds describe-db-instances \
  --query 'DBInstances[].[DBInstanceIdentifier,Engine,DBInstanceStatus]' \
  --output table

# 8. IAM 사용자 목록
aws iam list-users --output table
```

### 실습 3: 리전과 가용영역 이해 (30분)

**목표**: Multi-AZ 아키텍처 이해

```bash
# 사용 가능한 리전 목록
aws ec2 describe-regions --output table

# 현재 리전의 AZ 목록
aws ec2 describe-availability-zones \
  --query 'AvailabilityZones[].[ZoneName,State,ZoneId]' \
  --output table
```

**예상 출력** (서울 리전):
```
---------------------------------------------
|        DescribeAvailabilityZones          |
+------------------+------------+-----------+
|  ap-northeast-2a |  available |  apne2-az1|
|  ap-northeast-2b |  available |  apne2-az2|
|  ap-northeast-2c |  available |  apne2-az3|
|  ap-northeast-2d |  available |  apne2-az4|
+------------------+------------+-----------+
```

### 실습 4: 태그 기반 리소스 관리 (30분)

**목표**: 태그를 사용한 리소스 필터링

```bash
# 특정 태그가 있는 EC2 인스턴스 찾기
aws ec2 describe-instances \
  --filters "Name=tag:Environment,Values=production" \
  --query 'Reservations[].Instances[].[InstanceId,Tags[?Key==`Name`].Value|[0]]' \
  --output table

# 리소스에 태그 추가
aws ec2 create-tags \
  --resources i-1234567890abcdef0 \
  --tags Key=Environment,Value=production Key=Team,Value=platform
```

**토스플레이스 태그 전략**:
```
┌─────────────────────────────────────────────────────────────┐
│  필수 태그                                                   │
├─────────────────────────────────────────────────────────────┤
│  Environment: dev / staging / production                    │
│  Team: platform / payment / merchant                        │
│  Service: monitoring / api / web                            │
│  ManagedBy: terraform / manual                              │
│  CostCenter: platform-001                                   │
└─────────────────────────────────────────────────────────────┘
```
