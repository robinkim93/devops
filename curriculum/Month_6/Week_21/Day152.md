### VPC 구성 요소

| 구성 요소 | 역할 | 용도 |
|----------|------|------|
| VPC | 격리된 가상 네트워크 | AWS 리소스의 논리적 격리 |
| Subnet | VPC 내 IP 범위 분할 | Public/Private 영역 분리 |
| Internet Gateway | 인터넷 연결 게이트웨이 | 외부 트래픽 라우팅 |
| NAT Gateway | Private → 인터넷 | 아웃바운드 트래픽 허용 |
| Route Table | 트래픽 라우팅 규칙 | 서브넷별 라우팅 설정 |
| Security Group | 인스턴스 방화벽 (Stateful) | 인바운드/아웃바운드 규칙 |
| NACL | 서브넷 방화벽 (Stateless) | 추가 보안 레이어 |

### Security Group vs NACL

```
┌─────────────────────────────────────────────────────────────┐
│  Security Group vs NACL 비교                                │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  Security Group (Stateful):                                 │
│  - 인스턴스/ENI 레벨                                        │
│  - 허용 규칙만 (기본 Deny)                                  │
│  - 반환 트래픽 자동 허용                                    │
│  - 모든 규칙 평가                                           │
│                                                             │
│  NACL (Stateless):                                          │
│  - 서브넷 레벨                                              │
│  - 허용/거부 규칙                                           │
│  - 반환 트래픽 명시 필요                                    │
│  - 규칙 번호 순서대로 평가                                  │
│                                                             │
│  토스플레이스 사용 패턴:                                     │
│  - Security Group: 주요 접근 제어                           │
│  - NACL: 추가 보안 (특정 IP 차단 등)                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 🛠️ Part 2: 실습 (2시간)

### 실습 1: VPC 정보 조회 (30분)

```bash
# VPC 목록 조회
aws ec2 describe-vpcs \
  --query 'Vpcs[].[VpcId,CidrBlock,IsDefault,Tags[?Key==`Name`].Value|[0]]' \
  --output table

# 서브넷 목록 조회
aws ec2 describe-subnets \
  --query 'Subnets[].[SubnetId,VpcId,CidrBlock,AvailabilityZone,MapPublicIpOnLaunch,Tags[?Key==`Name`].Value|[0]]' \
  --output table

# 라우팅 테이블 조회
aws ec2 describe-route-tables \
  --query 'RouteTables[].[RouteTableId,VpcId,Routes[].{Dest:DestinationCidrBlock,Target:GatewayId}]'

# Internet Gateway 조회
aws ec2 describe-internet-gateways \
  --query 'InternetGateways[].[InternetGatewayId,Attachments[].VpcId|[0]]' \
  --output table

# NAT Gateway 조회
aws ec2 describe-nat-gateways \
  --query 'NatGateways[].[NatGatewayId,SubnetId,State]' \
  --output table
```

### 실습 2: Security Group 분석 (30분)

```bash
# Security Group 목록
aws ec2 describe-security-groups \
  --query 'SecurityGroups[].[GroupId,GroupName,VpcId]' \
  --output table

# 특정 Security Group 상세 정보
aws ec2 describe-security-groups \
  --group-ids sg-xxxxxxxxx \
  --query 'SecurityGroups[].{
    Name:GroupName,
    InboundRules:IpPermissions[].{
      Protocol:IpProtocol,
      FromPort:FromPort,
      ToPort:ToPort,
      Sources:IpRanges[].CidrIp
    }
  }'
```

**토스플레이스 Security Group 예시**:
```
┌─────────────────────────────────────────────────────────────┐
│  eks-worker-sg                                              │
├─────────────────────────────────────────────────────────────┤
│  Inbound:                                                   │
│  - 443/tcp from eks-control-plane-sg (API server)          │
│  - 10250/tcp from eks-control-plane-sg (kubelet)           │
│  - 53/tcp,udp from self (CoreDNS)                          │
│  - All traffic from self (pod-to-pod)                      │
│                                                             │
│  Outbound:                                                  │
│  - All traffic (0.0.0.0/0)                                 │
└─────────────────────────────────────────────────────────────┘
```

### 실습 3: CIDR 설계 실습 (30분)

```bash
# CIDR 계산기 사용 (ipcalc 설치)
brew install ipcalc  # macOS

# VPC CIDR 분석
ipcalc 10.0.0.0/16
# Network:   10.0.0.0/16
# Netmask:   255.255.0.0
# Broadcast: 10.0.255.255
# Hosts:     65534

# Subnet 분할 계획
ipcalc 10.0.0.0/16 -s 256 256 256 256 256 256
```

**권장 CIDR 설계**:
```yaml
vpc_cidr: "10.0.0.0/16"

subnets:
  public:
    - cidr: "10.0.1.0/24"    # 256 IPs (AZ-a)
    - cidr: "10.0.2.0/24"    # 256 IPs (AZ-b)
    - cidr: "10.0.3.0/24"    # 256 IPs (AZ-c)
  
  private:
    - cidr: "10.0.10.0/24"   # EKS nodes (AZ-a)
    - cidr: "10.0.11.0/24"   # EKS nodes (AZ-b)
    - cidr: "10.0.12.0/24"   # EKS nodes (AZ-c)
  
  database:
    - cidr: "10.0.20.0/24"   # RDS (AZ-a)
    - cidr: "10.0.21.0/24"   # RDS (AZ-b)
```

### 실습 4: VPC Flow Logs 이해 (30분)

```bash
# VPC Flow Logs 상태 확인

```
