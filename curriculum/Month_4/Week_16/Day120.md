## 📝 Part 4: 면접 대비 핵심 Q&A

### Q1: "GitOps CD 경험이 있나요?"

```
✅ 모범 답변:

"ArgoCD로 GitOps CD 파이프라인을 구축했습니다.

핵심 구현:
- Git 저장소를 Single Source of Truth로 사용
- ArgoCD Application으로 자동 배포
- App of Apps 패턴으로 다중 환경 관리
- Vault + ESO로 시크릿 분리

장점:
- 모든 변경이 Git에 기록되어 추적 가능
- Self-Heal로 수동 변경 자동 복구
- 롤백이 간단 (git revert)"
```

### Q2: "GoCD vs Jenkins 차이점은?"

```
✅ 모범 답변:

"GoCD는 CD 중심으로 설계되어 Value Stream Map이 핵심입니다.

GoCD 장점:
- Pipeline as Code 기본 지원
- Fan-in/Fan-out 의존성 관리
- 환경별 배포 추적이 직관적

Jenkins 장점:
- 플러그인 생태계가 풍부
- CI 기능이 강력

저는 CD 파이프라인에는 GoCD를, 복잡한 CI에는 GitHub Actions를 
사용하는 것이 효율적이라고 생각합니다."
```

### Q3: "카나리 배포를 어떻게 구현하나요?"

```
✅ 모범 답변:

"Argo Rollouts를 사용하여 구현했습니다.

전략:
1. 10% 트래픽 → 새 버전
2. 2분 대기 (메트릭 확인)
3. 25% → 50% → 75% → 100%

자동 롤백:
- AnalysisTemplate으로 성공률 모니터링
- 95% 미만이면 자동 롤백

장점:
- 코드 변경 없이 배포 전략 적용
- Prometheus 연동으로 메트릭 기반 결정"
```
