## 📚 Part 1: Helm 핵심 정리

### Chart 구조

```
myapp/
├── Chart.yaml          # 메타데이터
├── values.yaml         # 기본값
├── templates/          # K8s 매니페스트 템플릿
│   ├── deployment.yaml
│   ├── service.yaml
│   ├── _helpers.tpl    # 공통 템플릿 함수
│   └── NOTES.txt       # 설치 후 안내
└── charts/             # 의존성 차트
```

### 핵심 명령어

```bash
# 레포지토리
helm repo add bitnami https://charts.bitnami.com/bitnami
helm repo update
helm search repo bitnami

# 설치
helm install myapp bitnami/nginx
helm install myapp ./myapp -f custom-values.yaml
helm install myapp ./myapp --set replicas=3

# 업그레이드
helm upgrade myapp ./myapp
helm upgrade myapp ./myapp --set replicas=5

# 롤백
helm rollback myapp 1
helm history myapp

# 삭제
helm uninstall myapp

# 디버깅
helm template myapp ./myapp        # 렌더링만
helm install myapp ./myapp --dry-run --debug
```

### values.yaml 예시

```yaml
# values.yaml
replicaCount: 2

image:
  repository: nginx
  tag: "1.25"
  pullPolicy: IfNotPresent

service:
  type: ClusterIP
  port: 80

resources:
  requests:
    cpu: 100m
    memory: 128Mi
  limits:
    cpu: 500m
    memory: 512Mi

env:
  ENVIRONMENT: production
  LOG_LEVEL: info
```

### templates/deployment.yaml

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: {{ include "myapp.fullname" . }}
  labels:
    {{- include "myapp.labels" . | nindent 4 }}
spec:
  replicas: {{ .Values.replicaCount }}
  selector:
    matchLabels:
      {{- include "myapp.selectorLabels" . | nindent 6 }}
  template:
    metadata:
      labels:
        {{- include "myapp.selectorLabels" . | nindent 8 }}
    spec:
      containers:
      - name: {{ .Chart.Name }}
        image: "{{ .Values.image.repository }}:{{ .Values.image.tag }}"
        ports:
        - containerPort: 80
        resources:
          {{- toYaml .Values.resources | nindent 10 }}
        env:
        {{- range $key, $value := .Values.env }}
        - name: {{ $key }}
          value: {{ $value | quote }}
        {{- end }}
```

## 📚 Part 2: Kustomize 핵심 정리

### 디렉토리 구조

```
myapp/
├── base/
│   ├── kustomization.yaml
│   ├── deployment.yaml
│   └── service.yaml
└── overlays/
    ├── dev/
    │   └── kustomization.yaml
    ├── staging/
    │   └── kustomization.yaml
    └── prod/
        ├── kustomization.yaml
        └── patches/
            └── resources.yaml
```

### base/kustomization.yaml

```yaml
apiVersion: kustomize.config.k8s.io/v1beta1
kind: Kustomization

resources:
- deployment.yaml
- service.yaml

commonLabels:
  app: myapp
```

### overlays/prod/kustomization.yaml

```yaml
apiVersion: kustomize.config.k8s.io/v1beta1
kind: Kustomization

namespace: production
namePrefix: prod-

resources:
- ../../base

replicas:
- name: myapp
  count: 5

images:
- name: myapp
  newName: docker.io/user/myapp
  newTag: v1.2.3

patches:
- path: patches/resources.yaml
```

### 핵심 명령어

```bash
# 빌드
kustomize build overlays/prod

# kubectl과 통합
kubectl apply -k overlays/prod
kubectl diff -k overlays/prod

# 특정 리소스만
kustomize build overlays/prod | kubectl apply -f -
```

## 📚 Part 3: Helm vs Kustomize 비교

| 기준 | Helm | Kustomize |
|------|------|-----------|
| **접근 방식** | 템플릿 기반 | 패치 기반 |
| **학습 곡선** | 높음 (Go Template) | 낮음 (순수 YAML) |
| **재사용성** | Chart Repository | Base/Overlay |
| **복잡한 로직** | ✅ 조건문, 반복문 | ❌ 제한적 |
| **환경별 설정** | values 파일 | Overlay |
| **롤백** | helm rollback | Git revert |
| **디버깅** | helm template | kustomize build |

### 선택 가이드

| 상황 | 추천 |
|------|------|
| 복잡한 앱, 많은 옵션 | **Helm** |
| 단순한 환경별 차이 | **Kustomize** |
| 오픈소스 차트 사용 | **Helm** |
| 순수 YAML 선호 | **Kustomize** |
| 팀 표준 템플릿 | **Helm** |
| 기존 YAML 재사용 | **Kustomize** |

## 📚 Part 4: GoCD 핵심 개념

### Pipeline 구조

```
Pipeline
└── Stage (순차 실행)
    └── Job (병렬 가능)
        └── Task (순차 실행)
```

### GoCD vs 다른 CI/CD

| 도구 | 특징 | 주요 용도 |
|------|------|----------|
| **GoCD** | CD 중심, Value Stream | 복잡한 CD |
| **Jenkins** | 플러그인 풍부 | CI/CD 범용 |
| **GitHub Actions** | GitHub 통합 | CI 중심 |
| **ArgoCD** | GitOps, K8s 전용 | K8s CD |

### Pipeline as Code

```yaml
format_version: 10
pipelines:
  myapp-deploy:
    group: production
    materials:
      git:
        git: https://github.com/user/repo.git
        branch: main
    stages:
    - build:
        jobs:
          build:
            tasks:
            - exec:
                command: docker
                arguments: [build, -t, myapp, .]
    - deploy:
        approval:
          type: manual
        jobs:
          deploy:
            tasks:
            - exec:
                command: kubectl
                arguments: [apply, -f, manifests/]
```

## 🔑 핵심 명령어 요약

```bash
# Helm
helm install <name> <chart>
helm upgrade <name> <chart>
helm rollback <name> <revision>
helm template <chart>
helm uninstall <name>

# Kustomize
kubectl kustomize <dir>
kubectl apply -k <dir>
kustomize build <dir>

# ArgoCD + Helm
argocd app create myapp \
  --repo https://github.com/user/repo.git \
  --path charts/myapp \
  --dest-server https://kubernetes.default.svc \
  --dest-namespace default \
  --helm-set replicas=3

# ArgoCD + Kustomize
argocd app create myapp \
  --repo https://github.com/user/repo.git \
  --path overlays/prod
```
