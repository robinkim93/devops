## 📚 Part 1: ArgoCD + Helm 개념

### 연동 원리

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                     ArgoCD + Helm 동작 방식                                   │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│   방법 1: Helm Repository                                                    │
│   ┌─────────────┐         ┌─────────────┐         ┌─────────────┐           │
│   │ Helm Repo   │ ──────▶ │   ArgoCD    │ ──────▶ │ Kubernetes  │           │
│   │ (Bitnami)   │  Chart  │ helm template│ YAML   │   Cluster   │           │
│   └─────────────┘         └─────────────┘         └─────────────┘           │
│                                                                              │
│   방법 2: Git Repository                                                     │
│   ┌─────────────┐         ┌─────────────┐         ┌─────────────┐           │
│   │ Git Repo    │ ──────▶ │   ArgoCD    │ ──────▶ │ Kubernetes  │           │
│   │ (charts/)   │  Chart  │ helm template│ YAML   │   Cluster   │           │
│   └─────────────┘         └─────────────┘         └─────────────┘           │
│                                                                              │
│   ArgoCD는 내부적으로 `helm template`을 실행하여 YAML을 생성합니다.            │
│   실제 helm install/upgrade 명령을 사용하지 않습니다.                          │
│                                                                              │
└──────────────────────────────────────────────────────────────────────────────┘
```

### Helm vs Kustomize

| 특징 | Helm | Kustomize |
|------|------|-----------|
| 템플릿 방식 | Go 템플릿 | 패치 기반 |
| 복잡도 | 높음 | 낮음 |
| 유연성 | 매우 높음 | 중간 |
| 외부 Chart | 풍부한 생태계 | - |
| 학습 곡선 | 가파름 | 완만함 |

## 🛠️ Part 2: Helm Repository 방식

### 기본 구조

```yaml
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: nginx
  namespace: argocd
spec:
  project: default
  source:
    repoURL: https://charts.bitnami.com/bitnami  # Helm Repo URL
    chart: nginx                                  # Chart 이름
    targetRevision: 15.4.0                        # Chart 버전
    helm:
      values: |
        replicaCount: 3
        service:
          type: ClusterIP
  destination:
    server: https://kubernetes.default.svc
    namespace: nginx
  syncPolicy:
    automated:
      selfHeal: true
      prune: true
    syncOptions:
    - CreateNamespace=true
```

### Helm Repository 등록 (Private)

```bash
# ArgoCD에 Helm Repository 등록
argocd repo add https://charts.example.com \
  --type helm \
  --name my-charts \
  --username admin \
  --password secret

# 또는 Secret으로 등록
kubectl apply -f - <<EOF
apiVersion: v1
kind: Secret
metadata:
  name: my-helm-repo
  namespace: argocd
  labels:
    argocd.argoproj.io/secret-type: repository
stringData:
  type: helm
  url: https://charts.example.com
  name: my-charts
  username: admin
  password: secret
EOF
```

### 실습: Prometheus Stack 배포

```yaml
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: prometheus-stack
  namespace: argocd
spec:
  project: default
  source:
    repoURL: https://prometheus-community.github.io/helm-charts
    chart: kube-prometheus-stack
    targetRevision: 55.0.0
    helm:
      values: |
        prometheus:
          prometheusSpec:
            retention: 15d
            resources:
              requests:
                memory: 2Gi
              limits:
                memory: 4Gi
        grafana:
          adminPassword: admin123
          persistence:
            enabled: true
            size: 10Gi
        alertmanager:
          enabled: true
  destination:
    server: https://kubernetes.default.svc
    namespace: monitoring
  syncPolicy:
    automated:
      selfHeal: true
    syncOptions:
    - CreateNamespace=true
    - ServerSideApply=true  # CRD가 많은 경우 필수
```

## 🛠️ Part 3: Git Repository 방식

### 디렉토리 구조

```
infra-repo/
├── charts/
│   └── myapp/
│       ├── Chart.yaml
│       ├── values.yaml
│       ├── values-dev.yaml
│       ├── values-staging.yaml
│       ├── values-prod.yaml
│       └── templates/
│           ├── deployment.yaml
│           ├── service.yaml
│           ├── ingress.yaml
│           └── _helpers.tpl
└── apps/
    └── myapp-prod.yaml
```

### Application 정의

```yaml
# apps/myapp-prod.yaml
apiVersion: argoproj.io/v1alpha1
kind: Application
metadata:
  name: myapp-prod
  namespace: argocd
spec:
  project: default
  source:
    repoURL: https://github.com/myorg/infra-repo.git
    targetRevision: main
    path: charts/myapp           # Chart 경로
    helm:
      valueFiles:
      - values.yaml              # 기본 values
      - values-prod.yaml         # 환경별 values (우선순위 높음)
  destination:
    server: https://kubernetes.default.svc
    namespace: production
  syncPolicy:
    automated:
      selfHeal: true
      prune: true
```

### values 파일 예시

```yaml
# values.yaml (기본)
replicaCount: 1
image:
  repository: myapp
  tag: latest
  pullPolicy: IfNotPresent
resources:
  requests:
    memory: 128Mi
    cpu: 100m
  limits:
    memory: 256Mi
    cpu: 200m

---
# values-prod.yaml (프로덕션 오버라이드)
replicaCount: 3
image:
  tag: v1.2.3
  pullPolicy: Always
resources:
  requests:
    memory: 512Mi
    cpu: 500m
  limits:
    memory: 1Gi
    cpu: 1000m
autoscaling:
  enabled: true
  minReplicas: 3
  maxReplicas: 10
```

## 🛠️ Part 4: 고급 설정

### helm.parameters 사용

```yaml
spec:
  source:
    helm:
      parameters:
      - name: replicaCount
        value: "5"
      - name: image.tag
        value: "v2.0.0"
      - name: service.type
        value: "LoadBalancer"
```

### 환경변수에서 값 참조

```yaml
spec:
  source:
    helm:
      parameters:
      - name: image.tag
        value: $ARGOCD_APP_REVISION  # Git 커밋 해시
```

### 여러 values 파일 조합

```yaml
spec:
  source:
    helm:
      valueFiles:
      - values.yaml           # 1순위: 기본
      - values-common.yaml    # 2순위: 공통 설정
      - values-prod.yaml      # 3순위: 환경별 (우선순위 가장 높음)
```

### Secret values 처리

```yaml
# ArgoCD가 Git의 values-secrets.yaml을 복호화 (GPG/Age)
spec:
  source:
    helm:
      valueFiles:
      - values.yaml
      - secrets+age-import:///helm-secrets-private-keys/key.txt?values-secrets.yaml
```

## 📋 ArgoCD CLI 명령어

```bash
# Application 목록
argocd app list

# Application 상태 확인
argocd app get myapp-prod

# Helm values 확인
argocd app manifests myapp-prod

# 수동 Sync
argocd app sync myapp-prod

# Diff 확인
argocd app diff myapp-prod

# Helm 파라미터 변경
argocd app set myapp-prod -p image.tag=v2.0.0

# 롤백
argocd app rollback myapp-prod
```
