### 핵심 기능

| 기능 | 설명 | 예시 |
|------|------|------|
| **Secret Storage** | 암호화된 시크릿 저장 | DB 비밀번호, API 키 |
| **Dynamic Secrets** | 동적 자격 증명 생성 | AWS IAM, DB 사용자 |
| **Encryption as a Service** | 데이터 암호화/복호화 | Transit Engine |
| **Identity** | 인증 및 권한 관리 | K8s Service Account |
| **Audit** | 모든 접근 로깅 | 컴플라이언스 |

### Secret Engine 종류

| Engine | 용도 |
|--------|------|
| `kv` | 키-값 시크릿 저장 (가장 일반적) |
| `aws` | AWS IAM 동적 자격 증명 |
| `database` | DB 사용자 동적 생성 |
| `pki` | TLS 인증서 발급 |
| `transit` | 암호화/복호화 서비스 |

## 🛠️ Part 2: Vault Kubernetes 설치

### Helm Chart 설치

```bash
# Helm 레포 추가
helm repo add hashicorp https://helm.releases.hashicorp.com
helm repo update

# 네임스페이스 생성
kubectl create namespace vault

# values.yaml 작성
cat << 'EOF' > vault-values.yaml
global:
  enabled: true
  tlsDisable: false

server:
  image:
    repository: hashicorp/vault
    tag: "1.15.4"
  
  # HA 모드 (Production)
  ha:
    enabled: true
    replicas: 3
    raft:
      enabled: true
      setNodeId: true
      config: |
        ui = true
        listener "tcp" {
          tls_disable = 0
          address = "[::]:8200"
          cluster_address = "[::]:8201"
          tls_cert_file = "/vault/userconfig/vault-server-tls/tls.crt"
          tls_key_file  = "/vault/userconfig/vault-server-tls/tls.key"
        }
        storage "raft" {
          path = "/vault/data"
        }
        service_registration "kubernetes" {}
  
  # 스토리지
  dataStorage:
    enabled: true
    size: 10Gi
    storageClass: gp3
  
  # Ingress
  ingress:
    enabled: true
    ingressClassName: nginx
    hosts:
      - host: vault.example.com
    tls:
      - secretName: vault-tls
        hosts:
          - vault.example.com

# UI 활성화
ui:
  enabled: true
  serviceType: ClusterIP
EOF

# 설치
helm install vault hashicorp/vault \
  -n vault \
  -f vault-values.yaml
```

### Vault 초기화 및 Unseal

```bash
# Pod 상태 확인
kubectl get pods -n vault

# 초기화 (한 번만 실행)
kubectl exec -n vault vault-0 -- vault operator init \
  -key-shares=5 \
  -key-threshold=3 \
  -format=json > vault-init.json

# ⚠️ vault-init.json 안전하게 보관! (Unseal 키, Root 토큰)

# Unseal (각 vault Pod에 3번씩)
VAULT_UNSEAL_KEY1=$(cat vault-init.json | jq -r '.unseal_keys_b64[0]')
VAULT_UNSEAL_KEY2=$(cat vault-init.json | jq -r '.unseal_keys_b64[1]')
VAULT_UNSEAL_KEY3=$(cat vault-init.json | jq -r '.unseal_keys_b64[2]')

kubectl exec -n vault vault-0 -- vault operator unseal $VAULT_UNSEAL_KEY1
kubectl exec -n vault vault-0 -- vault operator unseal $VAULT_UNSEAL_KEY2
kubectl exec -n vault vault-0 -- vault operator unseal $VAULT_UNSEAL_KEY3

# 다른 Pod들도 동일하게 Unseal
kubectl exec -n vault vault-1 -- vault operator unseal $VAULT_UNSEAL_KEY1
# ...

# 상태 확인
kubectl exec -n vault vault-0 -- vault status
```

## 🛠️ Part 3: KV Secret Engine

### 로그인 및 Engine 활성화

```bash
# Root 토큰으로 로그인
ROOT_TOKEN=$(cat vault-init.json | jq -r '.root_token')
kubectl exec -it -n vault vault-0 -- vault login $ROOT_TOKEN

# KV v2 엔진 활성화
kubectl exec -it -n vault vault-0 -- vault secrets enable -path=secret kv-v2
```

### 시크릿 저장/조회

```bash
# 시크릿 저장
kubectl exec -it -n vault vault-0 -- vault kv put secret/myapp/config \
  username="admin" \
  password="super-secret-password" \
  api_key="abc123xyz"

# 시크릿 조회
kubectl exec -it -n vault vault-0 -- vault kv get secret/myapp/config

# 예상 출력:
# ====== Data ======
# Key         Value
# ---         -----
# api_key     abc123xyz
# password    super-secret-password
# username    admin

# JSON 형식
kubectl exec -it -n vault vault-0 -- vault kv get -format=json secret/myapp/config

# 특정 필드만
kubectl exec -it -n vault vault-0 -- vault kv get -field=password secret/myapp/config
```

## 🛠️ Part 4: Kubernetes 연동

### Kubernetes Auth 활성화

```bash
# K8s Auth 활성화
kubectl exec -it -n vault vault-0 -- vault auth enable kubernetes

# K8s API 설정
kubectl exec -it -n vault vault-0 -- vault write auth/kubernetes/config \
  kubernetes_host="https://$KUBERNETES_PORT_443_TCP_ADDR:443"
```

### Policy 생성

```bash
# myapp이 읽을 수 있는 시크릿 경로 정의
kubectl exec -it -n vault vault-0 -- vault policy write myapp - <<EOF
# KV v2에서 myapp 시크릿 읽기
path "secret/data/myapp/*" {
  capabilities = ["read", "list"]
}

# 메타데이터 읽기
path "secret/metadata/myapp/*" {
  capabilities = ["read", "list"]
}
EOF

# Policy 확인
kubectl exec -it -n vault vault-0 -- vault policy read myapp
```

### Kubernetes Role 생성

```bash
# Role 생성 (Service Account와 Policy 연결)
kubectl exec -it -n vault vault-0 -- vault write auth/kubernetes/role/myapp \
  bound_service_account_names=myapp \
  bound_service_account_namespaces=default,production \
  policies=myapp \
  ttl=24h
```

### 애플리케이션 Service Account 생성

```yaml
# myapp-sa.yaml
apiVersion: v1
kind: ServiceAccount
metadata:
  name: myapp
  namespace: default
```

```bash
kubectl apply -f myapp-sa.yaml
```

## 🛠️ Part 5: 애플리케이션에서 Vault 사용

### 방법 1: Vault Agent Injector

```yaml
# deployment.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: myapp
spec:
  template:
    metadata:
      annotations:
        # Vault Agent 활성화
        vault.hashicorp.com/agent-inject: "true"
        vault.hashicorp.com/role: "myapp"
        # 시크릿을 파일로 주입
        vault.hashicorp.com/agent-inject-secret-config.txt: "secret/data/myapp/config"
        vault.hashicorp.com/agent-inject-template-config.txt: |
          {{- with secret "secret/data/myapp/config" -}}
          export DB_USER="{{ .Data.data.username }}"
          export DB_PASS="{{ .Data.data.password }}"
          export API_KEY="{{ .Data.data.api_key }}"
          {{- end }}
    spec:
      serviceAccountName: myapp
      containers:
      - name: myapp
        image: myapp:latest
        command: ["/bin/sh", "-c", "source /vault/secrets/config.txt && ./app"]
```

### 방법 2: SDK 직접 사용

```go
// Go 예시
import (
    vault "github.com/hashicorp/vault/api"
    auth "github.com/hashicorp/vault/api/auth/kubernetes"
)

func getSecret() (string, error) {
    config := vault.DefaultConfig()
    config.Address = "http://vault.vault.svc:8200"
    
    client, _ := vault.NewClient(config)
    
    // K8s Auth
    k8sAuth, _ := auth.NewKubernetesAuth(
        "myapp",
        auth.WithServiceAccountTokenPath("/var/run/secrets/kubernetes.io/serviceaccount/token"),
    )
    
    _, _ = client.Auth().Login(context.TODO(), k8sAuth)
    
    // 시크릿 읽기
    secret, _ := client.KVv2("secret").Get(context.TODO(), "myapp/config")
    
    return secret.Data["password"].(string), nil
}
```
